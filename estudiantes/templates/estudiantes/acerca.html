Acerca del Proyecto

Que es

uniwebjacobo es una aplicacion web que permite gestionar el registro de estudiantes y productos. Permite ingresar datos, consultarlos en una lista y eliminar entradas de forma individual o en su totalidad.

Como se esta desarrollando

El proyecto se desarrolla utilizando el framework Django con Python como lenguaje del servidor. Las vistas se construyen con plantillas HTML propias de Django, la validacion de datos se realiza tanto en el cliente mediante JavaScript como en el servidor mediante Python, y los datos se almacenan en una base de datos SQLite local mediante el ORM de Django.
